# AISUF Website

Source repository for the AISUF website.

**Live site:** https://aisuf.org

## About

This repository contains the static AISUF website, including historical articles and selected related work.

The site is intentionally lightweight and is hosted using GitHub Pages.

## Site structure

- `index.html` — homepage
- `blogs/f/` — historical article pages
- `assets/css/` — site styles
- `assets/images/blogs/` — article images
- `404.html` — custom error page
- `robots.txt` — crawler configuration
- `sitemap.xml` — production sitemap
- `.nojekyll` — disables Jekyll processing for the static site
- `CNAME` — GitHub Pages custom-domain configuration

## Historical URLs

Historical AISUF article URLs are preserved under:

`/blogs/f/<article-slug>/`

These paths should not be changed without considering existing external links, bookmarks, references, and search indexing.
